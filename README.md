# Projeto Final – Bootcamp Data Analytics 2025  
### WoMakerCode • Instituto Localiza

---

## 📌 Visão Geral

Este repositório reúne todos os materiais produzidos para o **Projeto Final do Bootcamp de Data Analytics 2025**, realizado pela **WoMakerCode** em parceria com o **Instituto Localiza**.

O objetivo do projeto foi analisar a **Evolução Global do Câncer entre 2015 e 2024**, utilizando uma base com aproximadamente **50 mil registros**. A análise incluiu exploração inicial no Power BI com dados brutos, seguida de limpeza e manipulação no Google Colab.

---

## 🎯 Objetivo da Análise

- Entender a evolução dos casos de câncer entre 2015 e 2024.  
- Comparar os principais tipos e categorias da doença.  
- Identificar padrões regionais e globais.  
- Criar visualizações claras e acessíveis para apresentar insights.
